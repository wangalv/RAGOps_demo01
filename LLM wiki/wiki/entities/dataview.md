An [[obsidian]] plugin that runs queries over page frontmatter. Named in [[llm-wiki-idea-doc]]:
if wiki pages carry consistent YAML frontmatter (tags, dates, source counts — as this vault's
schema requires, see the vault's CLAUDE.md), Dataview can generate dynamic tables and lists over
them.
